# One global Round, not per-visitor games

The game could have started a fresh 20-question game for each visitor, which is
far simpler: no shared clock, no synchronisation, no mid-join problem. We chose
a single worldwide Round that every Player sees at the same second, because the
shared moment — everyone groaning at the same question — is the entire appeal
of the game-show framing, and a per-visitor game is just a single-player app
with a leaderboard bolted on.

## Consequences

A Player who arrives mid-Round scores zero for every Slot they missed. Their
Entry is unranked if they joined after the ranking threshold, so dropping in
late never damages an all-time average.
